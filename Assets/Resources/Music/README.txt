Zone exploration music (critical review C10)

Drop an mp3 here with one of these names and the zone plays it while exploring
(no scene editing needed). Zones without a file keep Castle_adventure_song.

  Explore_Forest.mp3      Forest Path
  Explore_Courtyard.mp3   Castle Courtyard
  Explore_Library.mp3     Library
  Explore_CastleHall.mp3  Castle Hall
  Explore_Tower.mp3       Treasure Tower
  Explore_CrownHall.mp3   Throne Room

The same songs can instead be dragged onto the MusicManager's "Per-Zone Exploration
Music" slots in the Zone 1 scene.
